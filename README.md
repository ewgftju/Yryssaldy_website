# Ырысалды Хамитова — сайт-визитка

Адаптивный сайт на HTML, CSS и JavaScript без сборки и зависимостей. Три языка: русский, казахский и английский.

**Сайт:** https://yryssaldy-khamitova.vercel.app/

**Репозиторий:** https://github.com/ewgftju/Yryssaldy_website

## Локальный просмотр

Откройте `index.html` в браузере или запустите `python3 -m http.server 8000` из корня проекта и перейдите на http://localhost:8000.

Интернет нужен для Google Fonts и внешних контактов; при недоступности шрифтов используются системные замены. Основной русский текст, изображения, контакты и раскрытие программ работают без JavaScript.

## Структура

- `index.html` — русский текст, семантическая разметка, контакты, метаданные.
- `styles.css` — адаптивный дизайн, мобильное меню, клавиатурный фокус и поддержка уменьшенной анимации.
- `script.js` — переводы, сохранение выбранного языка, мобильное меню и подготовка WhatsApp-ссылок.
- `assets/` — фотографии, значок сайта и контакт vCard.

## Содержание

Опыт и фотографии взяты из предоставленных презентаций. Контакты и направления коучинга перенесены с исходного сайта. Программы указаны как готовящиеся к запуску; даты и цены не добавлены. Ссылки WhatsApp открывают подготовленный текст, который посетитель отправляет самостоятельно.

## Публикация

Проект Vercel `yryssaldy-website` подключён к этому репозиторию. Изменения в ветке `main` публикуются автоматически.

Настройки Vercel: Framework Preset — Other, Build Command и Install Command — пустые, Root Directory — корень репозитория, Output Directory — по умолчанию. Сборка и сервер не требуются.

При смене домена обновите canonical, og:url и og:image в `index.html`, а также URL в `assets/yryssaldy.vcf`.

## Проверка

JavaScript проверен командой `node --check script.js`. Проверены внутренние якоря, файлы, 95 переводимых полей, переключение языков, раскрытие программ и мобильное меню. Десктопная и мобильная версии проверены в браузере; горизонтального переполнения нет.
